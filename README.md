## 🚀 Deploy to Vercel (Step-by-Step)

### Step 1 — Create a GitHub Account
Go to **github.com** → Sign Up (free). Use any email.

### Step 2 — Create a New Repository
1. Click the **+** button (top right) → **New repository**
2. Name it: `mactelecom-finance`
3. Set to **Public**
4. Click **Create repository**

### Step 3 — Upload the Project Files
On the repository page:
1. Click **uploading an existing file**
2. Drag and drop ALL files from this zip (maintaining folder structure)
3. Scroll down → Click **Commit changes**

### Step 4 — Deploy on Vercel
1. Go to **vercel.com** → Sign Up with your GitHub account
2. Click **Add New Project**
3. Find `mactelecom-finance` → Click **Import**
4. Leave all settings as default
5. Click **Deploy**

⏳ Wait ~60 seconds...

✅ **Your app is live!** Vercel gives you a URL like:
`https://mactelecom-finance.vercel.app`

**Bookmark that URL** — open it on any phone or laptop anytime.

## 📱 Add to Phone Home Screen

**Android (Chrome):**
1. Open the URL in Chrome
2. Tap the 3-dot menu → **Add to Home screen**
3. Tap **Add** — it now works like an app icon

**iPhone (Safari):**
1. Open the URL in Safari
2. Tap the Share button → **Add to Home Screen**
3. Tap **Add**

## 💾 Data Storage

Data is saved in your browser's **localStorage** — it persists across visits on the same device/browser. To use across multiple devices, just re-enter data on each device (or upgrade to a backend like Firebase in future).
